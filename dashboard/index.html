Denial Prevention Simulator

Northbridge Medical Group (fictional) · 11,967 claims · 14.0% denied, $5,419,266 denied. 76.6% of denials trace to a control that could have been checked before submission. This page sizes that opportunity and ranks the work queue that would capture it.

Fully synthetic data · no employer, patient or confidential information

How this page is built. Every value comes from a SQL query stored in dashboard/dashboard_config.json and run against data/claims.db by src/build_dashboard.py. Nothing is typed in by hand, so the dashboard cannot drift away from the analysis in sql/. Rebuild with python src/load_sqlite.py && python src/build_dashboard.py.

Limitations. Preventable is defined by a mapping from denial reason to an upstream control, which credits prevention to a control that might have failed anyway. The prevention opportunity is a modelled figure at 100% control effectiveness and is not a savings forecast; real capture depends on staffing and payer behaviour. Risk score weights are judgement, not a fitted model, so the score ranks claims and does not estimate probability. The data is fully synthetic.

Source: synthetic data generated by src/generate_data.py. No employer data, patient information, protected health information or confidential business information is used.

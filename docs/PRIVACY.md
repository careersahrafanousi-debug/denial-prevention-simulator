# Privacy and Data Handling Statement

This project uses fully synthetic data created for educational and portfolio purposes. It
does not use employer data, patient information, protected health information, or
confidential business information.

- Every record is generated by `src/generate_data.py` with a fixed seed. No file originated
  from a production system.
- Payers, the provider organization, service lines, and dollar amounts are invented.
- There are no member, patient, provider, or subscriber identifiers. The only keys are
  synthetic surrogates (`CLM-`, `PAY-`, `PR-`, reason codes).
- Denial reason categories reflect general industry terminology published in payer manuals
  and remittance advice standards. They are not drawn from any employer's configuration.
- No internal screenshots are included.
- All financial figures describe the synthetic dataset only. Modeled avoided exposure is
  clearly labelled as modeled and is not a savings claim.

CMS publishes synthetic Medicare claims files that are useful for learning claim structures.
Those files were not used here, and if referenced for structure they would be treated as a
technical reference only, never as evidence about a real patient population.
